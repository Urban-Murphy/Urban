# VIVIENDAS ECONÓMICAS: Modelo de construcción SIP para clase media-baja

## Descripción

**Viviendas Económicas (VE)** es un modelo de vivienda SIP diseñado para acceso de clase media-baja, basado en la estructura y cantidades de **AURA Esencial** pero con reemplazos estratégicos de materiales a precios económicos.

**Objetivo:** Reducir costo de construcción sin comprometer estructura SIP ni seguridad.

---

## Especificaciones

- **Superficie cubierta:** 73 m²
- **Distribución:** Estar-comedor-cocina, 2 dormitorios, antebaño, baño, galería, sendero perimetral
- **Estructura:** Kit SIP Base OSB 11.1 + EPS 15 kg/m³ (SIPCOR)
- **Durlock:** Estándar interior + RH en baño
- **Revestimiento exterior:** Placa cementicia 8mm pintada (en lugar de Siding LP)
- **Techo:** Chapa galvanizada sin pintar (en lugar de zinc con pintura)
- **Pisos:** Porcelanato económico (en lugar de premium)
- **Carpinterías:** Económicas (puertas MDF, aluminio blanco básico)
